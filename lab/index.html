Workflow

So entstehen die Experimente.

Kein Zauber, sondern ein Prozess. Am Beispiel von Covert Operations.

  1. 01

    Leitplanken

    Eine CLAUDE.md legt fest, wie der Agent arbeitet: erst denken, einfach halten, gezielt ändern, Ziele überprüfbar machen.

  2. 02

    Gemeinsame Aufgabenliste

    TASKS.md und TODO.md sind die Schnittstelle zwischen Mensch und Agent: Bugs, Features, Status – abgehakt wird erst, was committed ist.

  3. 03

    Iterieren

    Kleine Schritte, schnelles Feedback. Ich spiele, teste auf Desktop, iPad und iPhone und formuliere die nächste Aufgabe.

  4. 04

    Veröffentlichen

    Spielbare Stände laufen auf GitHub Pages. So lässt sich jeder Fortschritt direkt im Browser ausprobieren.
